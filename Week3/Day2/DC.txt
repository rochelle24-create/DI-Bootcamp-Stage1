2. MIN-MAX NORMALIZATION
Technique Used: Feature Scaling (Normalization)
python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler(feature_range=(0, 1))
df['salary_normalized'] = scaler.fit_transform(df[['salary']])
Formula:
normalized_value = (value - min) / (max - min)
Result: All values scaled to [0, 1] range
How We Practiced It:
Fit-Transform Pattern:
fit() learns min/max from data
transform() applies scaling
fit_transform() does both in one step
2D Array Input:
Pass df[['salary']] (2D array, not Series)
Required by sklearn for consistency
Feature Range Control:
feature_range=(0, 1) sets target scale
All salary values now between 0 and 1
Why It Matters:
Prevents features with large ranges from dominating ML models
Essential for algorithms like KNN, Neural Networks, K-Means
Makes comparison between different features fair
Before & After Example:
Original:  $30,000 to $228,000
Normalized: 0.0000 to 1.0000
Example: $149,000 to 0.6010 (60.1% of range)
3. DIMENSIONALITY REDUCTION (PCA)
Technique Used: Principal Component Analysis
python
# Step 1: Encode Categorical Variables
df_encoded = pd.get_dummies(df, columns=['job_title', 'job_type', 'experience_level', 'location', 'salary_currency'])
df_encoded = df_encoded.astype(int)

# Step 2: Extract Numeric Features
X = df_encoded.select_dtypes(include=[np.number]).drop('salary', axis=1)

# Step 3: Apply PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

# Step 4: Analyze Results
print(f'PCA: {X.shape[1]} features -> {X_pca.shape[1]} components')
print('Explained variance ratio:', pca.explained_variance_ratio_.round(4))
How We Practiced It:
A. One-Hot Encoding
pd.get_dummies() converts categorical columns to binary (0/1)
astype(int) converts boolean True/False to 1/0
Example:
  job_type: ['Full Time', 'Part Time', 'Contract']
  becomes:
  job_type_Full Time: [1, 0, 0]
  job_type_Part Time: [0, 1, 0]
  job_type_Contract: [0, 0, 1]
B. Feature Selection
select_dtypes(include=[np.number]) gets only numeric columns
.drop('salary', axis=1) removes target variable
Result: 335 features ready for analysis
C. PCA Application
PCA(n_components=2) reduces to 2 principal components
fit_transform() learns patterns and transforms data
explained_variance_ratio_ shows importance of each component
Results Achieved:
Input:  335 features (1171 samples)
Output: 2 components
Variance Explained: 16.97% + 13.87% = 30.83%
Why It Matters:
Curse of Dimensionality: Too many features leads to worse performance
Speed: Fewer features means faster training
Visualization: 2D/3D data can be plotted
Noise Reduction: Removes redundant information
Multicollinearity: Combines correlated features
