Modules Exercise

1.What is a module?
A module is a python file with python code that you can import from and use in another code file. For example, importing a function.

2.List three ways to import a module in Python.
There are three ways to import a module in python, using "import" to import an entire module, import part of a module by using "from" to use only a specific item from a module, using "import as" to use a shortend term for a module or a custom alias to be written and call that same module. You must define the module's alias at the beginnig with "import as" For example, from datetime import datetime as dt.

3.What is the purpose of importing?
The purpose of importing a module is to reuse code that someone has already written so you don't have to keep writing it from scratch each time in your code. This can be a module you write for yourself or a publicly available module like Python's built in modules.

4.List three examples when you would use the random module.
Random can be used in randomizing a number for a guessing game, randomizing from a list of names for a raffle draw or for randomizing a letter from the alphapet.

5.What is an ImportError?
An ImportError is usually when a module can't be found, maybe it was not imported correctly or at all. It's not found, doesn't exist or wasn't installed.

6.When would using an OrderedDict be useful?
Older versions of Python didn't maintain order so OrderedDict was used to do this. Latest versions of Python now maintain order but to keep it compatible with older versions you may still use this.

7.When would using a defaultdict be useful?
Defaultdict is useful when you want to count things or group things together without having to check if each key already exists in your dictionary.

8.What is the purpose of the following code: if __name__ == '__main__':
Only run this block of code if the file is being executed as the main program (not imported).
